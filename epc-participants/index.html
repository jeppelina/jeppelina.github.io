What this is. An unofficial, searchable index of the EPC2026 programme, built so you can find participants by country or institution (for example everyone from Sweden, or from Stockholm University) which the official programme site does not let you do.

How it was made. The public programme at epc2026.eaps.nl was read once and parsed into a structured list of people, papers, sessions and abstracts. Country is inferred from each person's stated affiliation, so it is approximate and a few institutions could not be placed. Not affiliated with EAPS or the EPC.

Built by Jesper Lindmarker.
